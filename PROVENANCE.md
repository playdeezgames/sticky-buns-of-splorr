# Provenance

Where everything that ships in the browser build comes from. The shipped notice is `odin/NOTICES.txt`
(copied to `dist/web/NOTICES.txt` by `make odin-dist`).

| What | Source | Licence | Notes |
|---|---|---|---|
| Game code (`odin/*.odin`) | TheGrumpyGameDev; port from the C++ original written with Claude Code | MIT (`LICENSE`) | The page copy discloses the AI use. |
| Font | DINOBYTE by mby, https://mby.itch.io/dinobyte, sheet `odin/assets/dinobyte/dbyte_1x.png` | CC BY 4.0 | Unmodified. SHA-256 `6e3aec513b6ee5acf56bb871bf04ea485908ac5f498a68e28afbd7a3f7e7cc4c`. Packed into `odin/font_data.odin` by `odin/tools/gen_font.py`. The author states no generative AI was used. The download has no licence file; the terms were read from the itch.io page on October 10, 2026 (`odin/assets/dinobyte/NOTICE.txt` records them). |
| `odin.js` and the Odin runtime in the wasm | Odin (`~/ODIN/core/sys/wasm/js/odin.js`, nightly `dev-2026-07-nightly:ab0131c`) | zlib-style (Ginger Bill) | Notice reproduced in `odin/NOTICES.txt`. |
| Cover and screenshots (`assets/`) | Generated by `tools/make_cover.py` from the game's own renderer | As the game | Only the shipped font and palette appear. |

## Not shipped, and why

- `romfont8x8.png` (the font the C++ build uses): provenance unresolved, so the Odin build does not use it. It is only
  referenced by the C++ build, which is to be retired after the Odin build ships. `ss/cover.png` is a screenshot drawn
  with it and is replaced by `assets/cover.png`.
