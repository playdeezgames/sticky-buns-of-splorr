GAME

  The original game was written in C++ in 2026. This browser build is a port to Odin,
  written with Claude Code (generative AI).

FONT
  The text is drawn with the DINOBYTE bitmap font by mby, https://mby.itch.io/dinobyte
  Licensed under Creative Commons Attribution 4.0 International (CC BY 4.0):
  https://creativecommons.org/licenses/by/4.0/
  The glyph sheet (dbyte_1x.png) is used unmodified. The game packs it into a table and
  tints each glyph with its own colours at draw time; the shapes are not changed.
